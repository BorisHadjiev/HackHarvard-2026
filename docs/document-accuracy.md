# Document reading accuracy

Generated by `npm run doc-accuracy` on a synthetic, labeled corpus: 30 people, 390 documents (90 photos with tilt, blur and JPEG compression). Every document runs through the same on-device pipeline the tenant app uses. Took 62s.

Synthetic documents use our own layouts, so these numbers measure the pipeline, not every real-world format. Real statements vary more.

False rejections: 0 of 180 genuine documents (0.0%).

## What this does not prove

- A careful forgery with consistent totals is only caught when the bank's own records contradict it. Without a bank connection it counts as "documents only, not independently verified", and the landlord sees that label.
- Tax forms cover a past year, so the bank check is a plausibility check, not an exact match.
- Signed PDFs are covered by unit tests (valid, untrusted, and changed after signing), not by this corpus.
